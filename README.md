# Realms of Fate

Realms of Fate is a custom fantasy action-RPG project built on the open-source
Delver Engine.

The project extends Delver with new gameplay systems, expanded magic and combat,
persistent progression features, modding support, community systems, and a
dedicated Modding Toolkit.

The original Delver Engine remains the technical foundation of the project.
Realms of Fate contains substantial custom gameplay and tooling work built on
top of that foundation.
